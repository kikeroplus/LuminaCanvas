# LuminaCanvas

ESP32-S3 と 240x320 の液晶で作る、天気・潮位・月・ニュース・地震情報の表示端末。InfoPanel (PC の監視端末) と同じハードウェアの 2 号機。
画面の左に天気・ニュースのページ、右の小窓にゲームのデモ (自動で遊ぶ) を次々に流す。

## 部品と配線

InfoPanel と同じ。

- CPU: ESP32-S3-DevKitC-1 N16R8 (Flash 16MB / PSRAM 8MB Octal)
- 液晶: ST7789 240x320 SPI

| 液晶 | S3 の GPIO |
|---|---|
| SCL (SCK) | 12 |
| SDA (MOSI) | 11 |
| CS | 10 |
| DC | 9 |
| RST | 8 |
| BL | 7 |

| 部品 | S3 の GPIO | 備考 |
|---|---|---|
| スイッチ 1〜4 | 13, 14, 1, 2 | もう片側は GND。内部プルアップで押すと LOW |
| ブザー | 6 | パッシブタイプ。トランジスタで駆動 (InfoPanel の README の回路) |

## 使うもの

- 描画: LovyanGFX (日本語フォント lgfxJapanGothic 入り)
- 天気: [Open-Meteo](https://open-meteo.com/) (岐阜市の緯度経度。鍵は不要)
- 天気概況: 気象庁の JSON (`overview_forecast/210000.json`、岐阜県)
- ニュース: NHK の RSS (主要・社会・経済・国際・科学・文化・暮らし・スポーツ)
- 潮位と月の出・月の入り: [tide736.net](https://tide736.net/) の API (四日市港。海上保安庁の推算。昨日・今日・明日の 3 回に分けて取る)
- 月の満ち欠け・次の満月と新月: 端末の中で計算 (Meeus『天文アルゴリズム』の式)
- 地震: 気象庁の JSON (`bosai/quake/data/list.json`、新しい順。先頭の 7 件分だけ読んで切る)

場所や取得の間隔は `src/config.h` にまとめてある。

## 画面

左 (208x240): 上に日付と時計、下にページ名。上の線は次のページへ自動で進むまでの残り。

| ページ | 内容 | 時間 |
|---|---|---|
| 現在の天気 | 天気の絵、気温、最高・最低、体感、湿度、風、降水確率、日の出・日の入 | 15 秒 |
| 24時間の予報 | 3 時間ごとの天気の絵、気温の線、1 時間ごとの降水確率 | 15 秒 |
| 週間予報 | 7 日分の天気、降水確率、最低・最高 (週の中での幅の棒) | 15 秒 |
| 日の出と潮位 | 日の入り (夜は日の出) までの時間、太陽の位置、昼の長さ。四日市港の今日の潮位の線、満潮・干潮の時刻、潮名と月齢、いまの潮位と次の満潮・干潮まで | 15 秒 |
| 月の満ち欠け | 月の絵 (満ち欠けの形)、月齢、呼び名、輝いている面の割合。月の出・南中・月の入り、月の入り (沈んでいれば月の出) までの時間。次の満月・新月の日時 | 15 秒 |
| 天気概況 | 気象庁 (岐阜地方気象台) の文章。長いときは画面を分けて送る | 1 画面 9 秒 |
| ニュース | 1 本ずつ、分野・時刻・見出し・要約 | 1 本 10 秒 × 5 本 |
| 地震情報 | 最近の 6 件。最大震度、震源地、時刻、M、深さ | 15 秒 |

右 (112x240): ゲームのデモ。45 秒ごとにシャッターで次へ。
TETRIS (落ち物) → INVADERS → BREAKOUT (ブロック崩し) → RUNNER (横スクロールのアクション) → SHOOTER (縦シューティング) → XEVIOUS (ゼビウス風。空の敵はザッパー、地上の敵は照準を合わせて爆弾。途中で母艦が来る。始まるときに短い曲) → QUEST (RPG 風。毎回作る地図を歩き、敵に出会うとコマンドで戦う。HP が減ると町の宿屋で休む) → MOUSE (迷路のネズミ。エサを集めてネコから逃げる。四隅のチーズを食べるとネコが逃げ出す) → SNAKE。

下の帯の右の丸: 緑 = つながっている、黄の点滅 = 取得中、赤 = WiFi なし。

## 操作

| スイッチ | 押す | 長押し (0.7 秒) |
|---|---|---|
| SW1 | 次のページ | 明るさ (明るい → ふつう → 暗い) |
| SW2 | 前のページ | 音量 (大 → 中 → 小 → 消す。切り替えるとその音量で確認の音) |
| SW3 | 次のデモ | ページの自動切り替えを止める / 再開 (止めている間は上の線が黄色) |
| SW4 | ニュースは次の記事、概況は次の画面 | 天気とニュースをすぐ取り直す |

## 作り方

1. `include/secrets.example.h` を `include/secrets.h` にコピーし、WiFi の接続先を書く。
2. PlatformIO でビルドして書き込む (書き込みは基板の「COM」側の USB 端子)。

色が反転していたら `src/lgfx_panel.h` の `cfg.invert`、赤と青が逆なら `cfg.rgb_order`、上下が逆なら `src/config.h` の `TFT_ROTATION` を変える。
